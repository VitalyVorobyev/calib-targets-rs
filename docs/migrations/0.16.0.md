# Migrating to 0.16.0

**Breaking, through the corner front end.** `calib-targets` moves to
`chess-corners` 2.0, whose configuration changed shape. Code that uses
`default_chess_config()` / the `chess` field of a params struct unchanged, and
reads only positions and labels, needs no change. Code that sets a refiner, the
position uncertainty or a known noise level, reads `AxisEstimate::sigma`, or
builds with `ml-refiner` does.

Positions and labels do not depend on any of these settings, with one
exception: the grid builder now drops clutter inside a board's cells before the
cell test (see the [CHANGELOG](../../CHANGELOG.md)), which recovers cells on
cluttered frames.

## The position covariance is off by default

0.15's unreleased covariance work reported a covariance on every corner. In
0.16 it is **opt-in**, as in `chess-corners` 2.0: weighting a real calibration
by it has not been shown to help, its real-data floor was fitted on one camera,
and it costs a per-image noise estimate plus a few percent of the corner pass.
`position_covariance` is `None` and `quality.noise_sigma` is unset unless you
ask for it. The quality's local residual (`local_residual_rms_px`) is measured
either way.

```rust,ignore
use calib_targets::detect::{default_chess_config, NoiseLevel, Uncertainty};

// Estimate the noise from each image.
let chess = default_chess_config().with_uncertainty(Uncertainty::Propagated {
    noise: NoiseLevel::Estimate,
});
// Or with a known sensor noise σ in gray levels (JPEG / demosaiced input).
let chess = default_chess_config().with_uncertainty(Uncertainty::Propagated {
    noise: NoiseLevel::Known(1.2),
});
```

| Binding | Before (1.x shape) | After |
|---|---|---|
| Rust | `.with_uncertainty(Uncertainty::Propagated)`, `.with_noise_sigma(σ)` | `.with_uncertainty(Uncertainty::Propagated { noise: NoiseLevel::Known(σ) })` |
| Python | `ChessConfig(uncertainty=Uncertainty.PROPAGATED, noise_sigma=σ)` | `ChessConfig(uncertainty=Uncertainty.propagated(noise_sigma=σ))` |
| JSON / JS | `"uncertainty": "propagated", "noise_sigma": σ` | `"uncertainty": {"propagated": {"noise": {"known": σ}}}` |
| C | `uncertainty = CT_UNCERTAINTY_PROPAGATED` (`0`) | `CT_UNCERTAINTY_PROPAGATED` is now `1`; `CT_UNCERTAINTY_OFF` is `0` |

`Uncertainty`, `NoiseLevel` and `ImageRefiner` are re-exported from
`calib_targets::detect`, so turning these on needs no `chess-corners`
dependency of your own. In C, `noise_sigma` is read only under
`CT_UNCERTAINTY_PROPAGATED`; setting it under `CT_UNCERTAINTY_OFF` is a
configuration error rather than a silently ignored value.

## The refiner is one optional stage

The ChESS strategy no longer carries a refiner. Its own localizer, the center of
mass of the response, is tuned by `strategy.chess.center_of_mass`; the
saddle-point refiner is the top-level `refiner`.

```rust,ignore
// Before
let chess = DetectorConfig::chess()
    .with_chess(|c| c.refiner = ChessRefiner::saddle_point());

// After
use calib_targets::detect::ImageRefiner;
let chess = DetectorConfig::chess().with_refiner(ImageRefiner::saddle_point());
```

| Binding | Before | After |
|---|---|---|
| Python | `ChessStrategyConfig(refiner=ChessRefiner.saddle_point())` | `ChessConfig(refiner=ImageRefiner.saddle_point())` |
| Python | `ChessStrategyConfig(refiner=ChessRefiner.center_of_mass(c))` | `ChessStrategyConfig(center_of_mass=c)` |
| JSON / JS | `"strategy": {"chess": {"refiner": {"saddle_point": {...}}}}` | `"refiner": {"saddle_point": {...}}` at the top level |
| JSON / JS | `"strategy": {"chess": {"refiner": {"center_of_mass": {...}}}}` | `"strategy": {"chess": {"center_of_mass": {...}}}` |
| C | `CT_REFINER_KIND_CENTER_OF_MASS` / `_SADDLE_POINT` | unchanged; the saddle-point kind now maps to the image refiner |

## Removed refiners and the `ml-refiner` feature

The ML and Förstner refiners are gone from `chess-corners` 2.0, and with them
the `ml-refiner` feature of every crate and of the Python package, Python
`ForstnerConfig` / `ChessRefiner.forstner()` / `ChessRefiner.ml()`, the
deprecated Python `RefinerConfig`, WASM `ForstnerConfig`, and C
`CT_REFINER_KIND_FORSTNER` with `ct_forstner_config_t` (the `forstner` member of
`ct_refiner_config_t` is gone, which changes that struct's layout). Use the
saddle-point refiner, which upstream measures as more accurate than either.

## Stale keys fail to load

Every config loader now rejects an unknown key, at every level, with an error
naming it: Rust serde, and Python `ChessConfig.from_dict`. A stored 1.x config
with `noise_sigma`, `"uncertainty": "propagated"` or a `strategy.chess.refiner`
fails to load instead of being dropped. Rewrite the moved keys as above.

## `AxisEstimate::sigma` is `fit_std_error`

The per-axis score is renamed after `chess-corners` 2.0: the least-squares
standard error of the axis fit, in radians — a fit-quality score for ranking and
gating axes, not a calibrated 1σ bound on the angle. Values are about 15%
smaller than the 1.x `sigma` at the median. Rename field accesses and JSON keys
(`axes[].sigma` → `axes[].fit_std_error` in corner clouds, WASM typings and
diagnostics traces). A corner cloud for `*_with_corners` written with the old
key no longer reads.

If you gate on the value yourself, re-check the gate on your data rather than
scaling it by a fixed factor. `projective-grid`'s own generic inputs
(`AxisObservation::sigma`, `LocalAxis::sigma_rad`) keep their names.

## Knobs that nothing read are gone

These fields were accepted and ignored; setting them is now an error, so a
config that relied on them says so instead of silently doing nothing.

| Removed | What to do |
|---|---|
| `PuzzleBoardParams.px_per_square` (Rust, Python, WASM, C) | Delete it; the PuzzleBoard detector never read it. |
| `CharucoParams.scan` | Keep only `scan.inset_frac`, as the top-level `inset_frac`. `marker_size_rel` and `border_bits` belong on `board` (they describe the printed target); `min_border_score`, `dedup_by_id` and `multi_threshold` were never read by ChArUco. |
| `aruco::ArucoScanConfig` | Set `ScanDecodeConfig` fields directly. |
| Python `ChessboardParams.chess` | Pass the corner config as `chess_cfg=` (chessboard) or set the params' own `chess` field (ChArUco, PuzzleBoard, marker board). |
| Python `OrientationClusteringParams`, `GridGraphParams`, `OrientationHistogram`, `GridGraph*`, `ChessboardDebug` | Delete; no detector used or returned them. |

```rust,ignore
// Before
let mut params = CharucoParams::for_board(board);
params.scan.inset_frac = 0.08;

// After
let mut params = CharucoParams::for_board(board);
params.inset_frac = 0.08;
```

In C, `ct_charuco_detector_params_t` loses `scan` and gains `inset_frac`, and
the ring width moves to `ct_charuco_board_spec_t::border_bits`.

A stored ChArUco config that omitted `scan` used to sample the marker as if it
filled its whole square (the defaulted `marker_size_rel = 1.0`). It now samples
the marker the board describes, which can only help decoding.

## One "board not found" convention

A miss — the image holds no board the detector can identify — is now reported
the same way on every surface, and a misuse is never mistaken for one.

| Surface | Miss | Misuse (bad image, spec or parameters) |
|---|---|---|
| Rust | `Err(e)` with `e.is_not_found()` | `Err(e)` with `!e.is_not_found()` |
| Python | `None` from every `detect_*` | `ValueError` |
| WASM | `null` from every `detect_*` | thrown error |
| C | `CT_STATUS_NOT_FOUND` | `CT_STATUS_CONFIG_ERROR` / `CT_STATUS_INVALID_ARGUMENT` |

What changes for you:

- **Python:** `detect_charuco`, `detect_puzzleboard`, `detect_puzzlepole` and
  their `_with_corners` / `_best` forms return `None` on a miss instead of
  raising `RuntimeError`. Replace `try … except RuntimeError` with a `None`
  check. An invalid config passed to `detect_chessboard` or a `_best` sweep now
  raises `ValueError` instead of returning `None`.
- **WASM:** the same detectors return `null` on a miss instead of throwing.
- **Rust:** match `err.is_not_found()` rather than enumerating nested variants.

```python
# Before
try:
    result = ct.detect_charuco(image, params=params)
except RuntimeError:
    result = None

# After
result = ct.detect_charuco(image, params=params)  # None when not found
```
