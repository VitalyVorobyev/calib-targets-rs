# Migrating to 0.17.0

**Breaking only for rarely used Rust surface.** 0.17.0 removes three items
that nothing in the workspace used. Code that calls the `detect_*` functions
or the detectors, and reads their results, needs no change. The Python
package, the WASM package and the C ABI (6.0.3, no type or layout change) have
no API change.

Labels change in one way: frames that used to deliver wrong labels on boards
blurred past readability now decline (see the
[CHANGELOG](../../CHANGELOG.md)).

## `RectifiedView` and `RectToImgMapper` are gone from `calib-targets-core`

They were result carriers that no function in the workspace produced. The
chessboard crate builds rectified views and returns its own types:

| Need | Call | Returns |
|---|---|---|
| One homography for the whole board (negligible lens distortion) | `calib_targets_chessboard::rectify_from_chessboard_result(&view, &detection, px_per_square, margin_squares)` | `RectifiedBoardView` (`rect`, `h_img_from_rect`, `h_rect_from_img`, grid extent) |
| A per-cell homography mesh (tolerates lens distortion) | `calib_targets_chessboard::rectify_mesh_from_grid(&view, &corners, &inliers, px_per_square)` | `RectifiedMeshView` (`rect`, origin, `cells_x`, `cells_y`, …) |

Both are reachable through the facade as `calib_targets::chessboard::…`. A
`RectToImgMapper::Global { h_img_from_rect }` corresponds to
`RectifiedBoardView::h_img_from_rect`; a `RectToImgMapper::Mesh` to a
`RectifiedMeshView`.

## `square_predict_grid_position` is gone

It forwarded to `projective-grid`'s lattice predictor. Call the predictor
directly (this needs `projective-grid` as a dependency of your own) and read
the prediction's `position`:

```rust,ignore
// Before
use calib_targets_core::square_predict_grid_position;
let p = square_predict_grid_position(&grid, idx);

// After
use projective_grid::{expert::lattice::predict_grid_position, LatticeKind};
let p = predict_grid_position(&grid, idx, LatticeKind::Square).map(|pred| pred.position);
```

The prediction also carries `n_axis_pairs`, the number of complete opposite
neighbour pairs it averages.

## The chessboard crate's `dataset` feature is gone

`calib-targets-chessboard/dataset` enabled `diagnostics` and an unused
dependency. Enable `diagnostics` instead:

```toml
calib-targets-chessboard = { version = "0.17", features = ["diagnostics"] }
```
