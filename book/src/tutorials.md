# Tutorials

Start-to-finish walkthroughs. Each one assumes no prior knowledge of the
library and ends with something that runs.

- **[Getting Started](getting-started.md)** — the complete workflow: choose a
  target, generate it, print it, detect it in Python and in Rust.
- **[Build and detect a PuzzlePole](tutorial_puzzlepole.md)** — the
  cylindrical target end to end, from choosing a diameter to 2D↔3D
  correspondences. Needs no printer: it renders the pole for you.

If you already know what you want and need the steps for one specific task,
the [How-to](howto.md) section is the shorter path. If you want to know how
something works rather than how to use it, read
[Algorithms](algorithms.md).
